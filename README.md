# Пееща ферма 🎵

Осем животинчета, осем ноти. Докосни някое и то танцува и пее.
Направено за малки ръчички: телефон, таблет или компютър.

| | | | | | | | |
|---|---|---|---|---|---|---|---|
| Слончо | Кравичка | Прасенце | Кученце | Лъвче | Коте | Зайче | Пиленце |
| До | Ре | Ми | Фа | Сол | Ла | Си | До |

- **●** запис: изсвири песничка, натисни пак и тя се повтаря в цикъл
- **▶** пуска и спира записа · **✕** го изчиства
- **★** животните сами пеят „Блещукай, звездице“
- на клавиатура: `1`–`8` или `A S D F G H J K`, а интервалът пуска песничката

Звукът се синтезира на място с Web Audio, без аудио файлове. 3D е Three.js.

Моделите са [Cube Pets](https://kenney.nl) от Kenney (CC0), вж. `models/LICENSE-kenney.txt`.

python -m http.server
